Flow

  • Upload: up to 4 letters at once (one per school), up to 4 pages each. JPG, PNG, HEIC, PDF, 10 MB per file. Each dropped file starts a new letter; "+ Add page" attaches more pages to the same letter. Phone camera capture. Manual entry stays available.
  • Read: one server-side extraction call per letter, run in parallel. Show per-letter progress. Never call the model from the browser.
  • Compare: as soon as all calls return, go straight to the side-by-side comparison. No blocking confirm step.
  • Accuracy guardrail: each column shows how many numbers were read with low confidence and what's missing, with a "Review" link. Editing recalculates the comparison. Cards with unchecked numbers say so until reviewed.
  • Partial failure: if one letter can't be read, the others still show. The failed column offers "Try another file" or "Enter by hand".
  • "Smallest gap" badge goes on the lowest remaining gap. "Biggest difference" line compares net cost.

Privacy rules (must have)

  • Process files in memory or delete from storage right after extraction.
  • Never store images, raw model output, names, addresses, student IDs or SSNs.
  • Session only unless a logged-in user saves the comparison.
  • Rate limit: about 10 letters per hour per visitor.
  • Privacy copy and policy to be reviewed by our terms lawyer before launch.

Calculation (prototype logic)

  • net = COA − free money − assistantships/work-study
  • federal = min(annual Unsub limit, net)
  • gap = max(net − federal, 0)
  • Limits here are placeholders (graduate 20,500 / professional 50,000). Use the values already in our calculator config. Don't hardcode.
  • Loans printed on the letter are shown for reference only and never reduce the gap. Grad PLUS lines get a "closed" tag.

Extraction output schema (per letter) 



  
Model instructions 

  
You are reading ONE graduate or professional school financial aid offer letter (all attached pages belong to the same letter).
Return ONLY JSON matching the schema. Rules:
1. Never invent numbers. If a value is not on the letter, return null.
2. Anything that must be repaid is a loan, even if the letter calls it an "award" or "grant". Check footnotes.
3. If amounts are per term/semester, set period="per_term", return number_of_terms, and convert every amount to annual.
4. For each field, return printed_label exactly as written on the letter (include "per term" if shown).
5. confidence="low" when text is blurry, cut off, ambiguous, or you inferred the category.
6. Classify loans: direct_unsubsidized, grad_plus, private, institutional, other.
7. Set program_level to "professional" for JD, MD, DO, DDS, PharmD, DVM and similar; otherwise "graduate".
8. If the pages are not an aid offer or are unreadable, return {"readable": false, "reason": "..."}.
9. Ignore and never return names, addresses, student IDs, SSNs or account numbers.
10. Put anything you cannot classify in notes.
